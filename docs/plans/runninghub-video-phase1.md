# RunningHub 视频接入第一阶段

## 目标

将 RunningHub 工作流 `2112923637551575042` 接入影策系统视频模型，使视频工作台、画布和自动做剧可以统一选择并调用该模型。

开发基线：`codex/runninghub-video-phase1`

## RunningHub 配置

- Base URL：`https://www.runninghub.ai`
- Workflow ID：`2112923637551575042`
- API Key：只允许管理员在后台配置，不写入代码、插件包、工作流 JSON、浏览器请求或日志。

## 第一阶段范围

- 文生视频；
- 图生视频；
- 参考视频；
- 参考音频；
- 提示词、时长、画幅和分辨率映射；
- RunningHub 任务提交、轮询和结果下载；
- `SUCCESS`、`FAILED`、`CANCELLED`、`CANCELED` 和超时处理；
- 系统视频模型目录；
- 视频工作台、画布和自动做剧；
- 使用现有影策渠道加价和积分系统。

第一阶段暂不实现图片工作流、音频工作流、多工作流后台管理和 NewAPI 接入。

## 计费规则

按 RunningHub 实际运行时间结算，不按用户请求的视频成片时长结算。

上游成本：

| 档位 | 成本 |
| --- | ---: |
| Standard | 6 元/小时 |
| Plus | 8 元/小时 |
| Ultra | 16 元/小时 |

Lite 暂不接入。

建议销售价：

| 档位 | 成本价 | 销售价 |
| --- | ---: | ---: |
| Standard | 6 积分/小时 | 9 积分/小时 |
| Plus | 8 积分/小时 | 12 积分/小时 |
| Ultra | 16 积分/小时 | 24 积分/小时 |

平台按 `usage.taskCostTime` 计算实际运行时间。`consumeCoins` 和 `consumeMoney` 作为上游成本和审计数据保存。任务采用预扣、成功后核算、多扣退款、少扣补扣；失败或确认取消时退款；无法确认上游状态时进入待核对。

## 后续扩展

RunningHub Provider 与具体工作流定义分离。后续通过新增或替换工作流定义支持图片、音频和其他视频工作流，包括版本、节点映射、输入字段、输出节点和默认参数，不为每个工作流重复实现请求代码。

## 验收标准

- 管理员可以配置 API Key；
- 系统视频模型列表能选择 RunningHub 模型；
- 自动做剧可以选择并提交该模型；
- 当前工作流能接收提示词、时长、比例、分辨率及参考素材；
- RunningHub 任务成功后视频被保存为影策资源；
- 失败、取消、超时不会继续显示生成中；
- 计费使用实际运行时间，并正确记录成本、售价、退款和利润；
- API Key、数据库、OSS 和线上账号数据不进入代码仓库。

## 当前实现状态

- RunningHub v2 Provider 已接入系统渠道视频路径；
- 画布旧工作流路径保持不变；
- `runninghub-workflow-video` 官方协议包已通过插件目录合同校验；
- 系统渠道任务已读取 `usage.taskCostTime` 进入按秒结算；
- RunningHub 视频能力默认值已覆盖当前工作流的时长、画幅、分辨率和参考素材上限；
- 当前仍需在真实登录环境配置 API Key、创建系统渠道价格档并完成一次真实 RunningHub 任务验收。

## 真实环境配置顺序

1. 在系统渠道中新增渠道，协议选择 `runninghub-workflow-video`，Base URL 填写 `https://www.runninghub.ai`，API Key 填写 RunningHub 积分 API Key。
2. 在渠道模型中新增模型，模型标识填写 `2112923637551575042`，能力选择“视频”。
3. 将计费模式设置为 `per_second`，配置销售价和成本价：Standard 为 9/6、Plus 为 12/8、Ultra 为 24/16 积分/小时。后台价格单位按影策的 microcredits 价格合同换算。
4. 保存并启用模型，确认模型目录显示“智墨 AI 视频”。
5. 在视频工作台先用纯提示词提交 5 秒、16:9、0.9 megapixels 的任务；成功后再测试参考图、参考视频和参考音频。
6. 在自动做剧中选择该视频模型，生成一个短镜头，确认结果能写回分镜。
7. 检查任务详情中的 RunningHub taskId、`usage.taskCostTime`、实际扣费、退款差额和成本记录。

素材参考输入仍需填写 RunningHub 企业级素材上传 Key；纯文生视频测试可以先留空。
